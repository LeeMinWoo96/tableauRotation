## ⚠️ SameSite 관련 주의사항

- Tableau Ticket 사용으로 인한 SameSite 이슈로 FireFox 기반 브라우저에서만 정상 동작
- 토큰 발급 요청 URL(태블로 서버)과 Node 서버 URL 일치 필요
  - 공인망 서버 사용시 동일 네트워크 필수
  - 로컬 개발환경의 경우 HTTPS 설정 및 SameSite=None 필수
